FAQ

Built for global developers accessing Chinese AI.

Is APIVEL a model provider?

APIVEL is an API gateway. We help global developers access leading Chinese AI models through a simpler, more reliable and OpenAI-compatible interface.

Which models are the priority?

The priority model families are Kimi, Qwen, DeepSeek and Seedance. APIVEL is also designed to expand toward GLM, MiniMax, Doubao, Seedream and other Chinese model providers.

Can I use it with coding agents?

Yes. APIVEL is positioned specifically for coding agents and agentic workflows, including tools such as Cline, Continue, Claude Code Router, Roo, browser-use and OpenAI-compatible SDK clients.

Does it support fallback routing?

Fallback routing is a core product direction. The goal is to reduce workflow failures caused by rate limits, provider instability, regional access issues or model-specific outages.

Is Seedance 2.0 available now?

Seedance 2.0 API is available through early access. Developers building AI video products, creative automation tools or marketing video workflows should apply for priority onboarding.
